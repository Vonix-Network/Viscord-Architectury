# 🤖 Viscord — Seamless Minecraft-Discord Integration
**By [Vonix.Network](https://vonix.network/)** | [📚 Full Documentation](https://github.com/Vonix-Network/Viscord) | [💬 Support Discord](https://vonix.network/discord)

Bridge your Minecraft server and Discord community with **real-time, bi-directional chat synchronization**. Let players and Discord members communicate effortlessly across platforms.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 💬 **Two-Way Chat Sync** | Minecraft ↔ Discord messages in real-time |
| 🎮 **Player Commands** | Execute server commands from Discord (admin only) |
| 📝 **Custom Messages** | Configure join/leave/death messages & chat formats |
| 🔔 **Status Updates** | Auto-post server start/stop/restart notifications |
| ⚙️ **Easy Setup** | Simple config to link your Discord bot |

---

## 🚀 Quick Commands

| Platform | Command | Description |
|----------|---------|-------------|
| Discord | `/list` or `!list` | View online players (Admin only) |
| Minecraft | `/discord` | Show Discord invite link |

📖 **[View all commands & permissions on GitHub →](https://github.com/Vonix-Network/Viscord)**

---

## 📥 Download & Install

1. Download for your platform (Fabric/Forge)
2. Place in `mods/` folder
3. Configure `viscord.json` with your bot token & channel IDs
4. Restart server

🔧 **[Detailed setup guide on GitHub](https://github.com/Vonix-Network/Viscord)**

---

## ⚠️ Dependencies

**Requires:** `Kotlin for Forge` (needed for OkHttp webhooks)
