Quick Installation

1

Download the Correct JAR

Choose the appropriate JAR file for your Minecraft version and mod loader from the downloads section.

2

Install to Server

Place the JAR file in your server's mods folder.

server/
├── mods/
│   └── Viscord-2.2.0-Fabric-1.21.1.jar
└── ...
3

Restart Server

Restart your Minecraft server to load Viscord. A configuration file will be generated automatically.

4

Configure Platform

Edit the generated config/viscord.json file to set up your preferred platform (Discord or Fluxer).

Success! Viscord is now installed and ready to configure.

Platform-Specific Setup

Discord Bot Setup - Complete Guide

1

Create Discord Application

Visit discord.com/developers/applications and create a new application:

  • Click "New Application"
  • Enter your server name (e.g., "My Server Viscord Bot")
  • Agree to Discord's Terms of Service
  • Click "Create"
2

Create Bot Account

In your application dashboard:

  • Go to "Bot" tab in the left sidebar
  • Click "Add Bot" and confirm
  • Click "Yes, do it!" when prompted
3

Configure Bot Intents (CRITICAL)

Enable the required intents for Viscord to function properly:

  • Scroll down to "Privileged Gateway Intents"
  • Enable "MESSAGE CONTENT INTENT" - Required for reading messages
  • Enable "SERVER MEMBERS INTENT" - Required for account linking
  • Save changes
IMPORTANT: Message Content Intent must be enabled or the bot cannot read chat messages!
4

Get Bot Token

Copy your bot token:

  • Under the bot's username, click "Reset Token"
  • Click "Copy" to copy the token to clipboard
  • Keep this token secure and private!
  • This token goes in your Viscord config as bot_token
SECURITY WARNING: Never share your bot token publicly or commit it to version control!
5

Invite Bot to Server

Generate an invite link and add the bot to your server:

  • Go to "OAuth2" → "URL Generator" in the left sidebar
  • Under "Scopes", select bot and applications.commands
  • Under "Bot Permissions", select these permissions:
REQUIRED PERMISSIONS:
✓ Send Messages
✓ Embed Links  
✓ Attach Files
✓ Read Message History
✓ Use External Emojis
✓ Add Reactions

OPTIONAL BUT RECOMMENDED:
✓ Manage Messages (for better formatting)
✓ Manage Webhooks (for webhook management)
  • Copy the generated URL at the bottom
  • Paste it into your browser and select your server
  • Click "Authorize" to add the bot
6

Create Discord Webhook

Create a webhook for sending messages to Discord:

  • In your Discord server, go to the channel where you want messages to appear
  • Click the gear icon (Channel Settings) next to the channel name
  • Go to "Integrations" → "Webhooks"
  • Click "New Webhook"
  • Name it something recognizable (e.g., "Minecraft Chat")
  • Optionally set an avatar for the webhook
  • Click "Copy Webhook URL"
  • This URL goes in your Viscord config as webhook_url
Pro Tip: You can create multiple webhooks for different channels (e.g., one for chat, one for server events).
7

Get Channel ID

Find your Discord channel ID:

  • In Discord, go to User Settings → Advanced
  • Enable "Developer Mode"
  • Right-click on your target channel
  • Click "Copy Channel ID" from the context menu
  • This ID goes in your Viscord config as channel_id
8

Configure Viscord

Update your Viscord configuration with the Discord details:

{
  "discord": {
    "bot_token": "YOUR_BOT_TOKEN_HERE",
    "channel_id": "YOUR_CHANNEL_ID_HERE", 
    "webhook_url": "YOUR_WEBHOOK_URL_HERE",
    "webhook_id": "",
    "invite_url": "https://discord.gg/yourserver"
  }
}
9

Test Your Setup

Verify everything is working:

  • Set enabled: true in your Viscord config
  • Restart your Minecraft server
  • Type a message in Minecraft - it should appear in Discord
  • Type a message in Discord - it should appear in Minecraft
  • Check server logs for any error messages

Security Best Practices

  • Never share your bot token - treat it like a password
  • Use environment variables for sensitive data in production
  • Enable only necessary permissions - principle of least privilege
  • Regularly rotate your bot token if you suspect it's compromised
  • Keep your bot application private - don't make it public unless necessary
  • Monitor bot activity for unusual behavior

Troubleshooting Bot Issues

Bot Not Connecting

  • Verify Message Content Intent is enabled in Discord Developer Portal
  • Check that the bot token is correct and not expired
  • Ensure the bot is actually in your Discord server
  • Check server logs for specific error messages

Bot Can't Read Messages

  • Message Content Intent must be enabled (most common issue)
  • Verify bot has "Read Message History" permission
  • Check that the channel ID is correct
  • Ensure the bot is actually in the target channel

Bot Can't Send Messages

  • Check webhook URL is valid and not expired
  • Verify bot has "Send Messages" permission
  • Ensure webhook hasn't been deleted from Discord
  • Test the webhook URL manually using a tool like Postman

Account Linking Not Working

  • Ensure Server Members Intent is enabled
  • Verify bot has "Read Message History" permission
  • Check that linking is enabled in config: "linking": {"enabled": true}
  • Ensure Discord-side /link command is implemented in your bot

Configuration Guide

Viscord uses a JSON configuration file located at config/viscord.json. The file is automatically generated on first run.

{
  "general": {
    "enabled": false,
    "platform": "discord"
  },
  
  "tridirectional": {
    "enabled": false,
    "discord_to_fluxer": true,
    "fluxer_to_discord": true,
    "show_source": true
  },
  
  "discord": {
    "bot_token": "YOUR_BOT_TOKEN_HERE",
    "channel_id": "YOUR_CHANNEL_ID_HERE",
    "webhook_url": "YOUR_WEBHOOK_URL_HERE",
    "webhook_id": "",
    "invite_url": ""
  },
  
  "fluxer": {
    "webhook_url": "",
    "event_webhook_url": "",
    "api_key": "YOUR_API_KEY_HERE",
    "port": 8080,
    "path": "/webhook"
  },
  
  "server": {
    "prefix": "[MC]",
    "name": "Minecraft Server",
    "avatar_url": ""
  },
  
  "formats": {
    "discord_to_minecraft": "[Discord] {username}: {message}",
    "minecraft_to_discord": "{message}",
    "webhook_username": "{prefix}{username}",
    "avatar_url": "https://minotar.net/armor/bust/{username}/100.png"
  },
  
  "events": {
    "send_join": true,
    "send_leave": true,
    "send_death": true,
    "send_advancement": true,
    "event_channel_id": "",
    "event_webhook_url": ""
  },
  
  "filters": {
    "ignore_bots": true,
    "ignore_webhooks": true,
    "filter_by_prefix": true,
    "show_other_server_events": true,
    "enable_chat_filter": false,
    "chat_filter_prefix": "!"
  },
  
  "bot": {
    "enabled": true,
    "format": "{online}/{max} players"
  },
  
  "linking": {
    "enabled": true,
    "code_expiry": 300
  },
  
  "advanced": {
    "debug_logging": false,
    "queue_size": 100,
    "rate_limit": 1000
  }
}

Configuration Options

Basic Settings

Setting Description Default
enabled Master toggle for Viscord false

Tridirectional Chat Settings

Setting Description Default
tridirectional.enabled Enable 3-way chat sync false
tridirectional.discord_to_fluxer Bridge Discord to Fluxer true
tridirectional.fluxer_to_discord Bridge Fluxer to Discord true

Important: For tridirectional chat, you must configure both Discord AND Fluxer settings, even if you primarily use one platform.

Available Commands

Viscord provides several commands for both administrators and regular players.

Admin Commands

Command Permission Description

Player Commands

Command Permission Description
/discord All players Show Discord invite link (if configured)
/viscord discord link All players Generate account link code for Discord integration

Complex Formatting Examples

Input:  §6§lGolden§r §9§oItalic§r §c§nand §l§munderlined strikethrough§r

Common Issues & Solutions

Connection Issues

Issue: Discord bot not connecting

Solution:

  • Verify your bot token is correct
  • Ensure Message Content Intent is enabled
  • Check that the bot has proper permissions
  • Verify the channel ID is correct
Issue: Messages not appearing in Discord

Solution:

  • Check webhook URL is valid
  • Ensure enabled: true in config
  • Verify bot has send messages permission
  • Check server logs for errors

Configuration Issues

Issue: Configuration file not generating

Solution:

  • Ensure server has write permissions
  • Check that the JAR is properly installed
  • Restart the server completely
  • Verify Java version compatibility
Issue: Tridirectional chat not working

Solution:

  • Ensure both Discord AND Fluxer are configured
  • Set tridirectional.enabled: true
  • Check webhook URLs for both platforms
  • Verify port forwarding for Fluxer receiver

Performance Issues

Issue: Server lag when using Viscord

Solution:

  • Enable debug logging to identify bottlenecks
  • Check network connectivity to Discord/Fluxer
  • Consider rate limiting if sending many messages
  • Monitor server resources usage

Debug Mode

Enable debug logging to troubleshoot issues:

{
  "debug_logging": true,
  "verbose_errors": true
}
Warning: Debug mode generates extensive logs. Use only when troubleshooting and disable in production.

Getting Help
