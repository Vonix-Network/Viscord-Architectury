# Viscord 2.4.0 - Quick Start

## 🚀 Installation

1. **Choose the correct JAR** for your Minecraft version and mod loader
2. **Place JAR** in your server's `mods` folder
3. **Restart server** to generate configuration in `config/viscord/`
4. **Configure** Discord or Fluxer in `config/viscord/viscord.json`
5. **Set `enabled: true`** and restart again

## 🎨 New in 2.4.0

- **Config Directory** - All files now in `config/viscord/` subdirectory
- **Reload Command** - `/viscord reload` for live config updates
- **Status Command** - `/viscord status` to check connection status
- **Command Rebrand** - All `/vonix` commands now `/viscord`
- **Async Safety** - No more server freezes during startup
